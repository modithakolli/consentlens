# ConsentLens intelligence records

These versioned records are product intelligence, not legal conclusions. Every record must include a source, review date, scope, and confidence. A missing or expired record must be presented as **unclassified**, never as safe.

`research-backlog.json` is a prioritized 75-service research queue. It is deliberately separate from published profiles: entries become public intelligence only after evidence review.

The extension remains local-first: these files ship with the extension and are not fetched while a person browses.
